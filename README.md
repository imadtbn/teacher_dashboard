# لوحة الأستاذ — حساب المعدلات والتقويم البيداغوجي 2026/2027

تطبيق ويب ثابت باللغة العربية لإدارة كشوف التقييم وحساب المعدلات للأطوار التعليمية الثلاثة في الجزائر، بالاستناد إلى المنشور الوزاري رقم 522/و.ت.و/م.ع.ت/2026.

## بنية المشروع

- index.html: البوابة الرئيسية وبيانات الأستاذ والمؤسسة.
- primary.html: واجهة التعليم الابتدائي.
- middle.html: واجهة التعليم المتوسط.
- secondary.html: واجهة التعليم الثانوي العام والتكنولوجي.
- rules.html: الدليل المرجعي للمعادلات والقواعد.
- assets/css/style.css: التنسيقات المشتركة والطباعة والاستجابة للشاشات الصغيرة.
- assets/js/app.js: إدارة الحالة، حساب المعدلات، الاستيراد، التحقق والجدولة.
- tests/grade-engine.test.cjs: اختبارات انحدار لمعادلات الأطوار وقواعد الجدولة.
- tests/browser-smoke.cjs: اختبار متصفح لسير العمل الأساسي والاستيراد والحفظ والتجاوب.
- .github/workflows/validate.yml: فحوصات CI على GitHub Actions.

## الخصائص التشغيلية

### البيانات والخصوصية
- يبدأ الملف الشخصي الجديد بأقسام وقوائم تلاميذ فارغة، دون أسماء أو علامات تجريبية.
- تحفظ البيانات محلياً في متصفح المستخدم عبر localStorage؛ لا توجد قاعدة بيانات مركزية أو مزامنة سحابية.
- يستخدم الإصدار الحالي مفتاح تخزين dz_teacher_grade_dashboard_v4_multi.
- عند وجود بيانات من الإصدار السابق، يحاول التطبيق ترحيل سجلات الأستاذ غير النموذجية إلى الإصدار الجديد. تبقى قيمة التخزين القديمة في المتصفح ولا تُحذف تلقائياً.
- إضافة التلميذ يدوياً تنشئ سجلاً بلا اسم أو علامات مفترضة. يجب على الأستاذ إدخال البيانات الفعلية.
- يربط studentKey سجلات التلميذ بين كشف المادة وكشف القسم عند الاستيراد المشترك أو الترحيل.

### الاستيراد والتصدير
تتوفر ثلاثة مسارات للاستيراد:
1. ملف Excel أو CSV.
2. لصق قائمة أو جدول من الحافظة.
3. رابط Google Sheets منشور أو متاح للعرض عبر الرابط.

يعرض التطبيق معاينة للبيانات قبل اعتمادها، ويحاول مطابقة عناوين الأعمدة العربية والفرنسية والإنجليزية، ويتجاوز الأسماء المكررة. لا تُنشأ علامات افتراضية للخانات غير الموجودة. يتطلب الاستيراد المباشر من Google Sheets صلاحية عرض مناسبة، وقد يعتمد نجاحه على سياسة CORS لدى Google؛ يمكن استخدام النسخ واللصق كبديل.

### الحسابات والتحقق
- الابتدائي: سلم /10 مع حالات التقييم الوصفي وإعفاء مواد الأنشطة من الاختبار.
- المتوسط: حساب معدل التقييم المستمر ثم المعدل الفصلي للمادة.
- الثانوي: معادلات اللغات والأعمال التطبيقية وبقية المواد، وفائض المشاريع والمطالعة.
- تُعرض تنبيهات عند تطابق نقاط المراقبة المستمرة مع علامة الفرض أو الاختبار، مع تجاهل الخانات الصفرية غير المقيمة لتفادي الإنذارات الكاذبة.
- تبدأ حقول شبكة المعايير بصفر عند عدم وجود تقييم محفوظ؛ لا يضع التطبيق علامات افتراضية تقديرية.
- يظهر تنبيه مدة اختبار الفرنسية (90 دقيقة) عند اختيار مادة الفرنسية في جميع مستويات التعليم المتوسط.
- في السنة الأولى ابتدائي لا يظهر معدل عددي في كشف القسم، ويشترط تسجيل المواظبة المنتظمة قبل احتساب الانتقال الآلي.
- عند ترحيل نتائج المادة إلى كشف القسم، تحفظ علامات الفرض والاختبار للمساعدة في كشف إعادة استخدامها في علامتي المشاريع والمطالعة.

### جدولة الفروض
تتضمن واجهات الأطوار أداة جدولة تتحقق من:
- فرض واحد للمادة في الفصل داخل القسم، حتى عند فصل المواد إلى مجموعات مستقلة.
- فرضين كحد أقصى في اليوم للقسم، ويُحتسبان عبر جميع مجموعات المواد التي تحمل اسم القسم نفسه.
- منع الفروض ضمن الفترات المغلقة المسجلة.
- انتهاء التصحيح والمعالجة قبل الاختبارات الفصلية بسبعة أيام على الأقل.

## التطوير والاختبارات

لا يتطلب المشروع إطار عمل Front-end أو خادماً خلفياً. لتشغيل اختبارات الحسابات محلياً:

    node --check assets/js/app.js
    node --test tests/*.test.cjs

اختبار المتصفح يستخدم Playwright وChromium:

    npm install --no-save playwright xlsx
    npx playwright install chromium
    node tests/browser-smoke.cjs

تُنفذ هذه الفحوصات آلياً عبر GitHub Actions عند الدفع إلى الفروع المشمولة أو فتح Pull Request إلى main.

## التطوير عبر الفروع

تُجرى التعديلات في فرع مستقل وتُراجع عبر Pull Request. لا تُدمج التغييرات في main قبل نجاح فحوصات CI والمراجعة اليدوية على الهاتف والحاسوب.
