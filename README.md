# 🎓 لوحة المعلم الذكية لحساب المعدلات وشبكة التقويم المستمر (2026/2027)
**مطابقة تماماً للمنشور الوزاري رقم 522/و.ت.و/م.ع.ت/2026 المؤرخ في 24 أكتوبر 2026 (وزارة التربية الوطنية - الجزائر)**

## 🏗️ الهيكلة المعمارية للمشروع (فصل كل طور في صفحة مستقلة)
- `index.html`: **الصفحة الرئيسية (البوابة المركزية)** لإدخال بيانات الأستاذ والمؤسسة، عرض ملخص الإحصائيات الشامل، والتوجيه المباشر لصفحة كل طور.
- `primary.html`: **صفحة طور التعليم الابتدائي** (سلم التنقيط `/10`، التقييم الوصفي والانتقال الآلي للسنة 1 ابتدائي، استثناءات الفصل 1 للإنجليزية سنة 3 والفرنسية والأمازيغية سنة 4، إعفاء مواد الأنشطة من الاختبار الفصلي، وحاسبة شبكة تقييم الميادين).
- `middle.html`: **صفحة طور التعليم المتوسط** (سلم التنقيط `/20`، حساب `م.ت.م` و `م.ف.م.ت`، وحاسبة شبكة تقييم نشاطات التلاميذ ذات المعايير الثلاثة: الانضباط والمواظبة، أنشطة داخل القسم، أنشطة خارج القسم).
- `secondary.html`: **صفحة طور التعليم الثانوي العام والتكنولوجي** (سلم التنقيط `/20`، تصنيف اللغات والأعمال التطبيقية `÷5` وبقية المواد `÷4`، احتساب فائض المشاريع الدراسية والمطالعة فوق `10/20` دون معامل، وحاسبة المراقبة المستمرة والشفوي والتطبيقي).
- `rules.html`: **الدليل التقني والمرجعي الكامل للمنشور الوزاري رقم 522/2026**.
- `assets/css/style.css`: ملف التنسيقات المشترك والطباعة الرسمية.
- `assets/js/app.js`: المحرك البرمجي المشترك لإدارة الحالة (`localStorage`)، التحقق الوزاري من عدم تطابق نقاط المراقبة المستمرة مع الفرض أو الاختبار، واستيراد/تصدير ملفات Excel (`.xlsx`).

## 🚀 طريقة رفع التعديلات إلى المستودع `imadtbn/teacher_dashboard`
فك الضغط عن الحزمة، ثم شغّل السكربت المرفق `push_to_github.sh` (أو نفّذ الأوامر التالية في الطرفية):

```bash
gh repo clone imadtbn/teacher_dashboard
cp -r index.html primary.html middle.html secondary.html rules.html README.md assets teacher_dashboard/
cd teacher_dashboard
git add .
git commit -m "feat: expand project into dedicated pages per educational stage (Primary, Middle, Secondary) per Circular 522/2026"
git push origin main
```
